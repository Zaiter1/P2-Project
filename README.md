# ThePodcastProject

Sistema de reservas para un estudio de podcast, desarrollado como proyecto final del curso de Programación II en ITLA.

## Descripción

Permite gestionar reservas de cabinas de grabación, incluyendo el equipo audiovisual solicitado, clientes y control de disponibilidad para evitar conflictos de horario.

## Tecnologías

- C# / .NET 10
- ASP.NET Core (Web API)
- Entity Framework Core
- SQL Server
- Arquitectura por capas (API, Application, Domain, Infrastructure, Persistence)

## Funcionalidades principales

- CRUD de reservas, clientes, cabinas y equipos
- Validación de conflictos de horario por cabina
- Relación de reservas con equipos audiovisuales disponibles
